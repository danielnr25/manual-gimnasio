# Horarios Nutrición

Permite programar la **disponibilidad y turnos de atención** del servicio de nutrición en cada sede.

![Horarios de nutrición](/img/administracion/horarios-nutricion-listado.png)

## Filtros y botones

| Elemento | Descripción |
| --- | --- |
| Sede | Filtra por sede (TODAS, IZAGA, STA VICTORIA, LAMBAYEQUE, SUMA, SAENZ PEÑA, BOLOGNESI). |
| Filas a mostrar | Registros por página. |
| **Buscar** | Aplica el filtro. |
| **+ Nuevo** | Registra un nuevo bloque horario de nutrición. |

## Columnas de la tabla

| Columna | Descripción |
| --- | --- |
| Día | Día de la semana de la atención. |
| Hora Inicio | Hora en que empieza el turno. |
| Hora Fin | Hora en que termina el turno. |
| Sede | Local donde se brinda el servicio. |
| Operaciones | Editar y Eliminar el turno. |
