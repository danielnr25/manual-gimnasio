# Cajas

Permite gestionar las **cajas registradoras, cuentas de depósito y medios de cobro** donde se registran los pagos.

## Pantalla principal

![Listado de cajas](/img/administracion/cajas-listado.png)

| Elemento | Descripción |
| --- | --- |
| Nombre | Busca una caja o cuenta por nombre. |
| Filas a mostrar | Registros por página. |
| **Buscar** | Aplica el filtro. |
| **+ Nuevo** | Abre el formulario de una nueva caja. |

## Crear una caja

1. Clic en **+ Nuevo**.

![Botón nuevo](/img/administracion/cajas-nuevo.png)

2. Complete el formulario y clic en **Registrar**.

![Formulario de caja](/img/administracion/cajas-formulario.png)

| Letra | Campo | Descripción |
| --- | --- | --- |
| a | Nombre | Nombre de la caja o cuenta. |
| b | Tipo | **Caja Chica** o **Caja Grande**. |
| c | Medio de pago | Efectivo, Depósito o Tarjeta. |
| d | V. Resumen C. Chica | **SI / NO**: si se muestra en el resumen de caja chica. |
| e | **Registrar** | Guarda la caja. |

## Columnas de la tabla

| Columna | Descripción |
| --- | --- |
| Nombre | Ej. Caja Principal, Caja Visa, BCP TRANSF - YAPE, BBVA TRANSF - PLIN, BANCO DE LA NACION. |
| Tipo | Caja Chica o Caja Grande. |
| V. Resumen C. Chica | Si aparece en el resumen de caja chica. |
| Medio Pago | Efectivo, Depósito o Tarjeta. |
| Caja Destino | Caja o cuenta receptora para operaciones específicas. |
| Operaciones | Editar y Eliminar. |
