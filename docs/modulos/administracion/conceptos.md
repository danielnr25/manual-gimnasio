# Conceptos Ingresos/Egresos

Permite administrar las **categorías y descripciones** de los movimientos de dinero (ingresos y egresos) del gimnasio.

![Conceptos de ingresos y egresos](/img/administracion/conceptos-listado.png)

## Filtros y botones

| Elemento | Descripción |
| --- | --- |
| Movimiento | Filtra por tipo de flujo financiero. |
| Nombre | Busca un concepto por nombre. |
| Filas a mostrar | Registros por página. |
| **+ Nuevo** | Registra un nuevo concepto. |

## Columnas de la tabla

![Tabla de conceptos](/img/administracion/conceptos-tabla.png)

| Columna | Descripción |
| --- | --- |
| Concepto | Ej. Adelantos Trabajador, Descuadre Caja, Otros Ingresos, Pago Completo Contrato. |
| Movimiento | OTROS EGRESOS, OTROS INGRESOS o PAGO DE CLIENTE. |
| Tipo | **INGRESO** o **EGRESO**. |
| Operaciones | Editar y Eliminar. |
