# Administración

El módulo de **Administración** reúne la configuración base del gimnasio: sedes, servicios, salas, cajas, horarios, numeración de documentos y otros datos que el resto del sistema utiliza.

::: tip Antes de empezar
Configure estos datos **antes** de registrar clientes o ventas. Por ejemplo, un servicio necesita una sede, y una sala necesita una sede.
:::

## Cómo ingresar

En el menú lateral izquierdo, haga clic en **Administración** para desplegar sus opciones.

## Opciones del módulo

| Opción | Para qué sirve |
| --- | --- |
| [Sedes](./sedes) | Registrar las sucursales del gimnasio y sus datos fiscales. |
| [Servicios](./servicios) | Crear membresías, planes y promociones con sus precios. |
| [Salas](./salas) | Administrar las salas de clases y sus horarios. |
| [Razón de venta](./razon-venta) | Registrar el origen o motivo por el que un cliente compra. |
| [Cajas](./cajas) | Configurar cajas, cuentas y medios de cobro. |
| [Horarios](./horarios) | Consultar los horarios por disciplina y sede. |
| [Horarios Nutrición](./horarios-nutricion) | Programar la atención del área de nutrición. |
| [Numeración de documentos](./numeracion-documentos) | Configurar series y correlativos de comprobantes. |
| [Pagos fijos](./pagos-fijos) | Controlar sueldos, alquileres y otros egresos recurrentes. |
| [Promociones](./promociones) | Gestionar campañas y descuentos. |
| [Conceptos Ingresos/Egresos](./conceptos) | Clasificar los movimientos de dinero. |

## Botones que se repiten en todo el módulo

Casi todas las pantallas funcionan igual:

| Elemento | Descripción |
| --- | --- |
| **Filtros** (Nombre, Sede, etc.) | Permiten ubicar un registro específico. |
| **Filas a mostrar** | Cantidad de registros por página (10, 25, 50). |
| **Buscar** | Aplica los filtros elegidos. |
| **+ Nuevo** | Abre el formulario para crear un registro. |
| **✔ Registrar** (verde) | Guarda la información ingresada. |
| **! Cancelar** (naranja) | Cierra el formulario sin guardar. |
| **Editar / Eliminar** | Columna *Operaciones* de cada fila. |
