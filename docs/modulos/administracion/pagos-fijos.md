# Pagos fijos

Controla los **egresos recurrentes** del gimnasio, como sueldos de personal, alquileres y otros pagos periódicos.

![Pagos fijos](/img/administracion/pagos-fijos-listado.png)

## Filtros y botones

| Elemento | Descripción |
| --- | --- |
| Sede | Filtra los pagos por sede. |
| Tipo | Filtra por categoría de pago. |
| Persona | Busca por nombre del trabajador o beneficiario. |
| **Generar Pagos Fijos** | Crea de forma masiva los pagos recurrentes programados. |
| **+ Nuevo** | Registra una nueva obligación fija. |

## Columnas de la tabla

![Tabla de pagos fijos](/img/administracion/pagos-fijos-tabla.png)

| Columna | Descripción |
| --- | --- |
| Concepto | Tipo de gasto (ej. Pago a Trabajador, Pago de Alquiler). |
| Monto | Cantidad asignada. |
| Trabajador | Persona beneficiaria del pago. |
| Sede | Local vinculado al gasto. |
| Operaciones | Editar y Eliminar. |
