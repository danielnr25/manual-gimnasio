# Razón de venta

Configura los **canales de origen o motivos** por los que un cliente compra o contrata. Ayuda a saber de dónde llegan las ventas (marketing y trazabilidad).

## Pantalla principal

![Listado de razones de venta](/img/administracion/razon-venta-listado.png)

| Elemento | Descripción |
| --- | --- |
| Nombre | Busca un canal u origen específico. |
| Filas a mostrar | Paginación del listado. |
| **+ Nuevo** | Añade una nueva razón de venta. |

## Crear una razón de venta

1. Clic en **+ Nuevo**.

![Botón nuevo](/img/administracion/razon-venta-nuevo.png)

2. Complete el formulario y clic en **Registrar**.

![Formulario de razón de venta](/img/administracion/razon-venta-formulario.png)

| Letra | Campo | Descripción |
| --- | --- | --- |
| a | Nombre | Fuente o motivo (ej. Referido, Cita presencial, Publicidad Facebook, Walk-in, Convenio, Pass Blue, Renovación, WhatsApp). |
| b | Código | Abreviatura interna (ej. R, AP, F, AD, W, AG, RE, IN, WH). |
| c | Considerado Lead | **SI / NO**: indica si califica como cliente potencial en el embudo de ventas. |
| d | **Registrar** | Guarda el registro. |

## Tabla

![Tabla de razones de venta](/img/administracion/razon-venta-tabla.png)

Columnas: **Nombre**, **Código**, **Considerado Lead** y **Operaciones** (Editar / Eliminar opciones personalizadas).
