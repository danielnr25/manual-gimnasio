# Promociones

Permite administrar las **campañas promocionales y descuentos** de las distintas sedes.

![Promociones](/img/administracion/promociones-listado.png)

## Filtros y botones

| Elemento | Descripción |
| --- | --- |
| Nombre | Busca una promoción por su nombre. |
| Sede | Filtra por local. |
| Filas a mostrar | Registros por página. |
| **+ Nuevo** | Registra una nueva promoción. |

## Columnas de la tabla

![Tabla de promociones](/img/administracion/promociones-tabla.png)

| Columna | Descripción |
| --- | --- |
| Nombre | Título de la promoción (ej. AFILIATE, ENERO). |
| F. Vencimiento | Fecha límite de vigencia. |
| Sede | Local donde está habilitada. |
| Operaciones | Editar y Eliminar. |
