# Introducción

Bienvenido al manual de usuario de **TAQINIGYM**, el sistema de gestión para gimnasios de Taqini.

Esta guía te explica, paso a paso, cómo usar el sistema en tu día a día: configurar tus sedes y servicios, registrar clientes y trabajadores, controlar tus cajas y administrar los accesos de tu equipo.

![Panel principal de TAQINIGYM](/img/panel-gimnasio.png)

::: info A quién va dirigido
Este manual es para administradores y personal de atención del gimnasio (counter, ventas, etc.). No necesitas conocimientos técnicos.
:::

## Antes de empezar

Necesitarás:

- Un dispositivo con conexión a internet (computadora, tablet o celular).
- Un navegador actualizado, como Chrome, Brave o Safari.
- Un **usuario y contraseña** asignados por el administrador del sistema.
- Un grupo de WhatsApp con el equipo de soporte de Taqini.

## Datos de acceso

Al contratar el servicio, el equipo de soporte te enviará por el grupo de WhatsApp:

| Dato | Ejemplo |
|------|---------|
| Enlace de tu sistema | `https://demogym.taqini.pe` |
| Usuario administrador | `tu-usuario` |
| Contraseña temporal | `********` |
| Celular de soporte | [+51 980 870 302](https://wa.me/51980870302) |

Los demás colaboradores recibirán su usuario y contraseña del administrador, quien los crea desde el módulo **Usuarios**.

::: danger Cambia tu contraseña
Por seguridad, cambia la contraseña temporal en tu primer ingreso. No la compartas con nadie.
:::

## Qué encontrarás en este manual

| Módulo | Qué aprenderás |
|--------|----------------|
| **Administración** | Configurar sedes, servicios, salas, cajas, horarios, numeración de documentos y más. |
| **Personas** | Gestionar clientes, proveedores y trabajadores. |
| **Usuarios** | Crear usuarios, asignar permisos y revisar la bitácora. |

::: warning Importante
Este manual se actualiza constantemente. Si algo no coincide con lo que ves en pantalla, escribe al soporte.
:::
